#+title: Start Here — Development Practices
#+filetags: :hub:devpractice:

This knowledge base is a portable, vendor-neutral collection of software-development
practices: how to write architecture decisions, how to structure commits and pull
requests, how to test adversarially, how to annotate code for both human and AI
readers, how to run periodic audits, how to run a build through a Makefile, and how
this very note-taking system works. It is not tied to any specific codebase, language,
or client — every note here is written as general guidance, adoptable in any project.

Before reading further: any internal link in this knowledge base uses the explicit
form ~[[id:NAMESPACE:node][display text]]~ — for example
[[id:practice:node-linking][Node Linking]]. Links that omit the ~id:~ prefix are not
guaranteed to resolve correctly in every system that can ingest notes like these. This
rule matters most if you are extending this knowledge base yourself — see
[[id:hub:molecular-notes-methodology][Molecular Notes Methodology]] before adding new
notes.

* Scope

Every note here describes a generic practice, not a fact about any one project. If a
note ever drifts into describing a specific codebase's file layout or a specific
organization's internal details, that is a defect in the note, not a feature — see
[[id:practice:kb-audit-checklist][KB Audit Checklist]].
